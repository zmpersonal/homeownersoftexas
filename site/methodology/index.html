Methodology

Primary source first. Explanation second.

The site is designed so a broken feed cannot silently become a broken fact.

Data pipeline

Official source → normalized snapshot → deterministic fact → explanatory page. Scheduled GitHub Actions retrieve public government sources and write versionable JSON snapshots into the repository. Cloudflare serves the generated static site.

Failure behavior

When a source request fails or an expected field disappears, the refresh job preserves the last known good metric and marks the source-health record as partial/stale. It does not replace a value with zero.

Derived calculations

Derived percentages use published source values and should be labeled as derived rather than agency-reported. For example, the change in average premium since 2019 is calculated from TDI's published annual premium series.

Legal-information boundary

Issue-routing pages identify possible authorities and public rules. They do not determine liability, deadline compliance, coverage, lien validity, damages or whether a user should file suit.

Historical continuity

Future ingestion should append time-series observations rather than overwrite old values. Historical values are essential for trend analysis, journalism and machine citation.
